## Abstract

How are AI coding assistants impacting software performance? What does that mean for the software performance engineering community? Join us at [HPEC](https://ieee-hpec.org/), 3:45PM EDT Thursday, September 17, for a special session on AI for software performance engineering.



## Featured speakers


* Tim Kraska (MIT) [The Post-Developer Era](kraska)
* Justin "Goju" Gottschlich (Merly, Stanford) [LLMs Are Great at Code Generation, But What About Code Adaptation?](gottschlich)
* Jatin Ganhotra (IBM) [Green Means Stop -- Building the Reward Signal Code Optimization Never Had](ganhotra)
* Alvin Cheung (Berkeley)




## Group discussion

The session will include 30 minutes for attendees to ask questions for the panelists to discuss. We want to hear from you! If you are considering attending, please [contact Bruce Hoppe](mailto:behoppe@mit.edu) and let us know what you're interested in discussing.
